# ERP Project - Kurumsal Kaynak Planlama Sistemi

Bu proje, bir işletmenin finans, stok ve kullanıcı yönetim süreçlerini dijitalleştirmek için Python ve Supabase kullanılarak geliştirilmiş modüler bir masaüstü uygulamasıdır.

## Öne Çıkan Özellikler
* **Finans Yönetimi:** Gelir/Gider takibi, kasa işlemleri ve otomatik finansal raporlama.
* **Stok Takibi:** Ürün giriş-çıkış kontrolü ve kritik stok seviyesi uyarıları.
* **Bulut Veritabanı:** Supabase entegrasyonu ile verilerin güvenli ve senkronize bir şekilde saklanması.
* **Kullanıcı Yetkilendirme:** Güvenli giriş sistemi ve rol tabanlı erişim kontrolü.

## Kullanılan Teknolojiler
* **Dil:** Python
* **Arayüz:** PyQt / Qt Designer (.ui dosyaları ile dinamik tasarım)
* **Veritabanı:** MySQL (Yerel) & Supabase (Bulut)
* **Güvenlik:** .env ile çevre değişkenleri yönetimi ve şifreleme.
